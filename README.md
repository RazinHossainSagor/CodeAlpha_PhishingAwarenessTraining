# CodeAlpha_PhishingAwarenessTraining

## Overview
This repository contains the deliverables for **Task 2: Phishing Awareness Training** completed as part of the Cyber Security Internship at CodeAlpha.

The project provides comprehensive educational content and an interactive Python module designed to help individuals and employees identify social engineering attacks, spoofed domains, and credential-harvesting emails.

---

## Key Training Topics Covered
1. **Anatomy of a Phishing Email:**
   - Spoofed display names & mismatched sender domains.
   - Artificial urgency, threats, or enticing financial lures.
   - Deceptive hyperlinks and mismatched destination URLs.
   - Suspicious attachments (e.g., `.xlsm`, `.exe`, `.scr`, `.zip`).

2. **Common Types of Phishing:**
   - **Spear Phishing:** Targeted attacks against specific individuals or roles.
   - **Whaling:** Targeting high-level executives (C-level).
   - **Smishing & Vishing:** Phishing conducted via SMS or voice calls.
   - **Watering Hole Attacks:** Compromising websites frequently visited by targets.

3. **Prevention & Defensive Checklist:**
   - Always verify the Top-Level Domain (TLD) and exact spelling.
   - Hover over hyperlinks before clicking to inspect destination URLs.
   - Enable Multi-Factor Authentication (MFA/2FA) on all critical services.
   - Never provide credentials via unsolicited links.
